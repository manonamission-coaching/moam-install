# MOAM Powerhouse — Installer

Setup scripts for the Man on a Mission Powerhouse.

This repository holds the two installer scripts only. It is public so the
one-line install command can reach it without a login. Nothing else lives here.

## Install

**Mac** — open Terminal and paste:

```
curl -fsSL https://raw.githubusercontent.com/manonamission-coaching/moam-install/main/mac.sh | bash
```

**Windows** — open PowerShell and paste:

```
irm https://raw.githubusercontent.com/manonamission-coaching/moam-install/main/win.ps1 | iex
```

## Before you run it

You need three things first:

1. A Claude account (Max recommended, Pro works)
2. A free GitHub account at github.com
3. Your invitation accepted — send your GitHub username to Matt and he will
   send it. Check github.com/notifications if you cannot find the email.

Without step 3 the installer has nothing to download.

## What it does

Installs the developer tools, connects your computer to GitHub, downloads your
Powerhouse workspace, installs Claude Code, and puts a launcher on your Desktop.
Running it twice is safe.
